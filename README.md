# RAFD-

# RAFD is a smart agricultural decision-support platform designed to help farmers adapt to changing environmental conditions. Using NASA Earth observations, local soil information, and crop characteristics, RAFD helps farmers analyze agricultural challenges, assess crop suitability, and explore crop rotation strategies that support soil health, conserve water, and improve farm resilience.
